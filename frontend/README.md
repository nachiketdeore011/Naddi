# Frontend - Nadi Diagnosis Dashboard

## Tech Stack
- React 18 + TypeScript
- Vite for build
- Tailwind CSS for styling
- Recharts for data visualization
- Lucide React for icons
- React Router for navigation

## Setup
```bash
npm install
npm run dev
```

## Pages
- **Dashboard** - System overview, stats, recent patients
- **Patients** - CRUD for patient records
- **Patient Detail** - Sessions, pulse waveform, analysis results

## Development
The dev server runs on port 3000 and proxies `/api` requests to the backend at `localhost:8000`.
